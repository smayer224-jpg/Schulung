# Regeln für dieses Projekt

## Sprache
- Antworte immer auf Deutsch.
- Benutze einfache Sprache: kurze Sätze, wenig Fachwörter. Wenn ein Fachwort nötig ist, erkläre es kurz.

## Technik
- Benutze nur HTML, CSS und JavaScript.
- Keine externen Bibliotheken oder Frameworks: keine CDNs, kein npm, keine Pakete.

## Sicherheit
- Schreibe niemals Passwörter, API-Schlüssel, Tokens oder andere Zugangsdaten in Dateien.
